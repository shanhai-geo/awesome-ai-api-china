## AI大模型API

### 通义千问（阿里）
- 官网：https://tongyi.aliyun.com
- API文档：https://help.aliyun.com/zh/dashscope
- 模型：qwen-turbo / qwen-plus / qwen-max
- 特点：中文理解能力最强

### 文心一言（百度）
- 官网：https://yiyan.baidu.com
- API文档：https://cloud.baidu.com/doc/WENXINWORKSHOP
- 模型：ernie-4.0 / ernie-3.5
- 特点：知识面广，知识截止日期新

### 智谱GLM（清华）
- 官网：https://open.bigmodel.cn
- 模型：glm-4 / glm-4-flash（flash免费）
- 特点：性价比极高，响应速度快

### 讯飞星火
- 官网：https://xinghuo.xfyun.cn
- 模型：spark-v3.5
- 特点：语音能力突出

### Moonshot Kimi
- 官网：https://kimi.moonshot.cn
- 模型：moonshot-v1-8k/32k/128k
- 特点：超长上下文（128K）

### MiniMax
- 官网：https://www.minimaxi.com
- 模型：abab6/abab5.5
- 特点：多模态，创意写作
